# Security Policy

Vijaya Construction is a static marketing site. It does not use serverless functions in this repository.

## Reporting a vulnerability

Please report suspected security issues to partner@vijaya.construction.

Include:

- affected URL or file
- reproduction steps
- expected impact
- any safe proof-of-concept details

Please do not submit test enquiries, spam live contact forms, or access data that is not yours while reporting an issue.
